## Project Migration
### From Altium to Workspace (Cloud)
- To send the current project to the workspace go to the left project panel.
- Right click the project and select ''Make Project Available Online''.
- Version control should be ON to allow multiple people to work on the project and also save version history.
- Click advanced to go to change the folder where the project is to be saved.
### From other Sources
- File -> Import Wizard

## Project Creation and Storage
- File -> New Project
- We get a selection of Project type as PCB, Multiboard or Harness.
- Templates for these are already setup in Altium workspace to choose from.
- Right click on any file and click ''Explore'' and you can see the local folder to see the address of the file.
- Older  versions should be added to ''Legacy Projects'' folder in a Projects folder.

## Using Workspace Templates
- Open Explorer panel from Panels button on bottom right. (K + R)
- Expand ''Managed Contents'' and then ''Templates''
- We can also add new Templates in this Folder for our later use.
- to check the template of a given file go to properties on bottom left while the page is open.
- Templates could be changed throughout the Workspace by just updating the template in templates folder.

## Updating the Altium Project
- Altium 365 is based on Git Based version control system.
- Green tick after each file indicates that the cloud based workspace is up to date with the local file version.

## Permissions and Sharing
- In online version select the project and use the share button on Top.
- or in the offline version go to panels -> Explorer and select the project -> top right corner share button.
- View/Edit access, Shared with.
- Guest access.
- We can store personal files in Shared with me folder.
- under advanced settings we can manage who is able to download or share the project.

## Collaboration with Comments and Tasks
- right click or Ctrl+Alt+C
- Comments could be applied to a point or an object such as Component or a wire or area of the design.
- click pen icon to make any free hand drawings.
- To make a to do list and assigned to team members.
- Panels -> Comments and Tasks.
- Comments and Tasks do not alter the doc so no need to sync them.

## History and Design Comparisons
- Right click on any file and go to ''History and Version Control'' -> Show project history
- Scroll back in time and select a version and click view to see what the project looked like at that time.
- two versions could be compared just like Git.
- Releases could be compared as well.

## Project Releaser
- right click on the project and click project releaser.
